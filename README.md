# UNIFET Shipping Invoice Generator

A simple, self-contained web app that generates professional invoices matching the **UNIFET Shipping Company** template.

## Features

- Form fields:
  - **Bill To** (name & address)
  - **Security Fee**
  - **Delivery Fee**
  - **Invoice Date** & **Time**
  - Due Date & Invoice #
- Live preview that closely follows the original UNIFET design:
  - Circular red logo with ship + stars
  - Company name styling
  - Red header table (META / PAYMENT / TOTAL / DESCRIPTION)
  - Red truck with yellow “UNIFET” container (SVG)
  - Handwritten-style “Unifet” signature + circular company stamp
- One-click **Print / Save as PDF**
- Fully client-side (no server required)

## How to use

1. Open `index.html` in any modern browser.
2. Fill in the form.
3. Click **Generate / Update Invoice**.
4. Click **Print / Save as PDF**.

## Files

- `index.html` — Complete single-file application (HTML + CSS + JS)
