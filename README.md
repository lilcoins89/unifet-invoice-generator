# UNIFET Shipping Invoice Generator

A simple, self-contained web app to generate professional invoices matching the UNIFET Shipping Company template.

## Features

- Fill form fields:
  - **Bill To** (name & address)
  - **Security Fee**
  - **Delivery Fee**
  - **Invoice Date**
  - **Time**
  - Due Date & Invoice #
- Live preview of the invoice with the same branding (logo, table layout, red truck illustration, Unifet signature + stamp)
- One-click **Print / Save as PDF**
- Fully client-side (no server required)

## How to use

1. Open `index.html` in any modern browser.
2. Fill in the form.
3. Click **Generate / Update Invoice**.
4. Click **Print / Save as PDF** to download or print.

## Files

- `index.html` — Complete single-file application (HTML + CSS + JS)
